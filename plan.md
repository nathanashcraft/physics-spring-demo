# Spring Physics Demonstration

## Goal

Build a small browser-based demonstration using only HTML, CSS, and JavaScript. It should help users see how spring constant, spring length, and load affect a spring’s response.

## Must-have features for the first version

1. **Adjustable inputs** — Let users set the spring constant and resting length, then choose a load as either a hanging mass or an applied force.
2. **Animated spring response** — Provide a button to start the motion. Show the spring stretching or compressing under the load, bouncing, and gradually settling.
3. **Live readouts** — Display the selected inputs and the spring’s changing length and amount of stretch or compression.

## Optional for later

- Pause and reset controls
- Additional visual customization

## Open details

Specific input ranges, units, and visual styling have not been decided yet.
